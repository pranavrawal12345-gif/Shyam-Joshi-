Algorithmic Breakdown

How the AI Agent Works

A deep dive into the 5 distinct mathematical and lexical stages executed upon every query.

01

Step 1: Keyboard Input Capture

The agent attaches an asynchronous event listener to the input buffer, recording user typing events and string length in real time without blocking the UI thread.

02

Step 2: Lowercase & Normalization

The raw string is converted to lowercase and sanitized using regex word boundaries to prevent punctuation collisions and ensure case-insensitive matching (e.g. "AMAZING!" → "amazing").

03

Step 3: Keyword Dictionary Matching

The normalized token stream is evaluated against two calibrated sets: 10 Positive Lexicons (`good`, `great`, `love`, etc.) and 10 Negative Lexicons (`bad`, `hate`, `awful`, etc.).

04

Step 4: Score Comparison & Polarity Math

The frequency scores $S_{pos}$ and $S_{neg}$ are compared. Net polarity $\Delta = S_{pos} - S_{neg}$ is computed alongside a confidence percentage derived from token dominance.

05

Step 5: Sentiment Classification & Explanation

The final class (`POSITIVE`, `NEGATIVE`, or `NEUTRAL`) is rendered along with confidence gauges, spectrum needle animation, and transparent reasoning bullets.

Theoretical Foundations

Understanding AI Agent Paradigms

Explore the foundational concepts bridging classical symbolic AI and modern neural architectures.

CONCEPT 01

What is an AI Agent?

An AI Agent is an autonomous entity that perceives its environment through sensors (e.g. keyboard input events), processes the received state through internal reasoning mechanisms, and executes actions (e.g. rendering classifications and explanations) to achieve a defined objective.

Perception → Reasoning → Action Loop
CONCEPT 02

What is Rule-Based AI?

Rule-Based AI (also known as Classical or Symbolic AI) relies on explicitly programmed human knowledge represented as deterministic IF-THEN rules, keyword lexicons, and logic trees. It guarantees 100% predictability, auditability, and total transparency without black-box opacity.

Deterministic • Explainable • Auditable
CONCEPT 03

Rule-Based AI vs Machine Learning

While Machine Learning (ML / LLMs) learns statistical representations from massive training datasets, Rule-Based Systems excel at constrained domains where strict compliance, zero hallucination, instant execution, and zero inference costs are paramount.

Exact Precision vs Statistical Approximation

DETERMINISTIC LOGIC

The 8 Processing Steps

sentiment_agent_algorithm.js 
// 1. Receive keyboard input
const rawInput = textarea.value;

// 2. Convert text to lowercase
const text = rawInput.toLowerCase();

// 3. Scan for positive keywords (10 lexicons)
const posMatches = POSITIVE_DICT.filter(word => 
  regexMatch(text, word)
);

// 4. Scan for negative keywords (10 lexicons)
const negMatches = NEGATIVE_DICT.filter(word => 
  regexMatch(text, word)
);

// 5. Count keyword occurrences
const posScore = posMatches.length;
const negScore = negMatches.length;

// 6. Compare counts & 7. Return classification
let sentiment = "NEUTRAL";
if (posScore > negScore) sentiment = "POSITIVE";
else if (negScore > posScore) sentiment = "NEGATIVE";

// 8. Simulate processing delay & dispatch UI
await simulateAgentThinking(1000);
renderResults({ sentiment, posScore, negScore });
